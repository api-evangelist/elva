# Elva

> Elva is the system that discovers every API in your codebase, understands and scores them, governs what each audience can access, and exposes them to developers, applications, and AI agents through documentation, SDKs, and hosted MCP servers. Elva reads source code directly, so no OpenAPI spec is required. Built by Theneo. Sometimes described as an API control plane for the agentic era.

Elva is built by Theneo, an API documentation platform used by 20,000 companies.

## Product

- [API Catalog](https://getelva.ai/catalog.md): Automatic API discovery, organization, and scoring
- [API Contracts](https://getelva.ai/contracts.md): Define, enforce, and publish contracts with field-level control
- [MCP Management](https://getelva.ai/mcp.md): Generate, host, and govern MCP servers
- [API Testing](https://getelva.ai/testing.md): Generated tests and chaos suites
